약속캐치 개인정보처리방침

약속캐치는 사용자의 통화 녹음 파일과 약속 관련 정보를 분석하여 캘린더 등록을 돕기 위해 필요한 최소한의 정보만 처리합니다.

기기 내 온디바이스 분석
등록 버튼을 눌렀을 때만 캘린더 저장
임시 데이터 작업 후 정리
핵심 안내 약속캐치는 통화 녹음, 최근 통화 감지, 메신저 알림 및 사용자가 직접 실행한 현재 대화 AI 분석 기능을 제공하며, 사용자가 허용한 범위 안에서만 권한과 데이터를 사용합니다.

1. 수집 및 처리하는 정보

  • 사용자가 직접 선택한 통화 녹음 파일
  • 최근 통화 녹음 자동 감지 과정에서 확인한 녹음 파일 정보
  • 녹음 또는 메시지에서 추출한 날짜, 시간, 장소, 상대 이름, 메모 정보
  • 캘린더 등록을 위한 일정 정보
  • 구독 상태 확인 및 복원을 위한 결제 상태 정보
  • 카카오톡 알림 기반 약속 감지 사용 시, 사용자가 허용한 알림에 표시된 메시지 텍스트
  • 현재 대화 AI 분석 기능 사용 시, 플로팅 팻을 누른 세션 동안 분석 시점에 현재 화면에 실제로 표시된 메시지 텍스트
  • 사용자가 수정하거나 삭제한 약속·할 일 결과를 바탕으로 생성된 개인화 학습 기록

2. 정보 처리 목적

  • 통화 녹음 파일 분석
  • 약속 후보 추출 및 사용자 확인
  • 캘린더 일정 등록
  • 통화 종료 후 자동 감지 및 알림 제공
  • 카카오톡 알림 기반 약속 감지
  • 사용자가 직접 실행한 현재 대화 AI 분석
  • 프리미엄 구독 상태 확인 및 구매 복원

3. 정보 처리 방식

  • 음성 및 메시지 분석은 사용자 기기 안에서 온디바이스 방식으로 처리되며, 통화 녹음과 메시지 원문은 외부 서버로 전송하지 않습니다.
  • 현재 대화 AI 분석은 사용자가 플로팅 팻을 눌러 세션을 시작한 동안에만 동작하며, 분석 시점에 화면 밖에 있는 메시지나 메신저 전체 대화 데이터베이스를 수집하지 않습니다.
  • 분석 과정에서 생성되는 임시 데이터는 작업 후 정리됩니다. 추출된 약속과 할 일 후보는 사용자가 확인할 때까지 기기 안에 임시 보관됩니다.
  • 사용자가 등록 버튼을 누를 때만 캘린더에 일정이 저장됩니다.
  • 사용자가 취소하거나 등록이 완료되면 보류 중인 약속 데이터는 정리될 수 있습니다.

4. 제3자 제공

앱은 사용자의 통화 녹음 파일이나 추출된 약속 정보를 외부에 판매하거나 임의로 제공하지 않습니다.

다만 다음 기능은 운영상 외부 플랫폼의 처리를 포함할 수 있습니다.

  • Google Play 결제 및 구매 복원
  • Android 시스템 캘린더 제공자 사용

5. 권한 사용 안내

  • 오디오 접근 권한: 사용자가 선택한 녹음 파일 분석
  • 캘린더 권한: 일정 등록
  • 전화 상태 권한: 통화 종료 자동 감지
  • 알림 권한: 자동 감지 결과 표시
  • 알림 접근 권한: 카카오톡 알림 기반 약속 감지
  • 접근성 권한: 사용자가 지원 메신저에서 플로팅 팻을 눌러 현재 대화 AI 분석을 실행할 때, 분석 시점에 현재 화면에 실제로 표시된 메시지 텍스트를 읽어 약속 및 할 일을 찾는 데 사용

사용자는 기기 설정에서 언제든지 권한을 허용하거나 철회할 수 있습니다.

6. 보관 및 삭제

  • 앱은 원본 녹음 파일을 별도로 영구 저장하지 않습니다.
  • 임시 분석 데이터는 작업 완료 후 정리됩니다. 추출된 후보는 사용자가 등록하거나 삭제할 때까지 기기 안에 보관됩니다.
  • 개인화 학습 기록은 기기 안에만 저장되며, 사용자가 개별 항목을 삭제하거나 설정에서 전체 학습 기록을 초기화할 때까지 보관됩니다.
  • 사용자는 앱 삭제를 통해 로컬 저장 데이터를 제거할 수 있습니다.

7. 사용자 권리

  • 앱 권한 철회
  • 자동 감지 기능 비활성화
  • 카카오톡 감지 기능 비활성화
  • 현재 대화 AI 분석 접근성 권한 비활성화
  • 개인화 학습 기록의 개별 삭제 또는 전체 초기화
  • 앱 삭제를 통한 로컬 데이터 제거

8. 문의

개인정보 처리와 관련한 문의가 있는 경우, 앱 배포 페이지 또는 별도 안내된 연락처를 통해 문의할 수 있습니다.

9. 변경 사항

이 개인정보처리방침은 앱 기능 또는 관련 법령 변경에 따라 수정될 수 있으며, 중요한 변경이 있을 경우 앱 또는 배포 페이지를 통해 안내할 수 있습니다.
